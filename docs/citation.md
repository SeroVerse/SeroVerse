# Citing SeroVerse

If you use **SeroVerse** (`seroverse`, `seroref`, `kbank`, `serogen`, or `seroepi`) in your research, genomic serotyping, glycomic analyses, or epidemiological publications, please cite the software using the metadata below.

=== "BibTeX"

    ```bibtex
    @software{Stanton_SeroVerse,
      author       = {Stanton, Thomas David},
      title        = {{SeroVerse: Core data structures, graph algorithms, and async database clients for bacterial genomics, glycomics, and sero-epidemiology}},
      url          = {https://seroverse.github.io/SeroVerse/},
      repository   = {https://github.com/SeroVerse/SeroVerse},
      license      = {GPL-3.0-only}
    }
    ```

=== "APA"

    ```text
    Stanton, T. D. SeroVerse: Core data structures, graph algorithms, and async database clients for bacterial genomics, glycomics, and sero-epidemiology [Computer software]. https://github.com/SeroVerse/SeroVerse
    ```
